# Kathi Family Tree — Static Site

What this is
- A simple static HTML/CSS/JS family tree for:
  - Parents: Kathi Vinay Kumar and Thriveni Bakki
  - Children: Akshayani Kathi and Rishi Vikyath Kathi

How to use
- Open `index.html` in a browser.
- Double-click any name to edit it in-place.
- Double-click an avatar to refresh initials based on the name.

Hosting
- Push these files into a GitHub repository and enable GitHub Pages (or)
- Serve locally: `python -m http.server 8000` then open http://localhost:8000
